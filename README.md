# OPDaily

A daily "lethal puzzle" for the One Piece Card Game — Wordle-style. One fixed board position per
day; find lethal on the current turn in as few actions as possible.

- **Rules engine**: [`optcg_rules`](../optcg_rules) (`@optcg/core`), vendored as prebuilt
  tarballs in `vendor/`. OPDaily contains **no card logic** of its own.
- **Puzzle guarantee**: a solver proves every shipped puzzle has exactly one minimal-action
  winning line that wins against *every* legal opponent defence (blockers, counters, triggers).
- **Scoring**: fewest actions, ties broken by time. Per-puzzle leaderboard.

## Layout

```
packages/puzzle   puzzle schema, engine runner, minimax solver, verifier
apps/api          Fastify + Postgres API (Railway)
apps/web          Next.js frontend (Vercel)
puzzles/          authored puzzle JSON (verified in CI)
vendor/           pinned @optcg/* tarballs + ENGINE_VERSION.json
scripts/          vendor-engine, build-card-metadata, verify-puzzles
```

## Workflow

```
npm run vendor:engine     # re-pack engine from ../optcg_rules (records git SHA)
npm run build:cards       # regenerate card metadata for puzzles' referenced cards
npm run verify:puzzles    # prove each puzzle has a unique minimal lethal line
npm test                  # unit + API tests
```

Puzzle solutions (`puzzles/*.solution.json`) are generated by the verifier, server-only, and
never shipped to the browser.
